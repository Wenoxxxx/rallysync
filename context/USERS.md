
*** FUNCTIONAL REQUIREMENTS for All Users

** Feature Description/User Story

- User Sign-Up | New users can create accounts by providing their personal information to access the system.
- User Sign in | Secure login authentication for their specific dashboard.
- Forgot password | User can reset their password via verification link sent to their email and can recover their account.
- Dashboard User | can see real-time updates on ongoing tournaments and court bookings that relevant to their dashboard.
- Notifications and Reminders | User can receive automated email/push alerts for upcoming bookings, match times, schedule changes and important events.
